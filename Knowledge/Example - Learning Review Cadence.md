# Example - Learning Review Cadence

## Summary

A learning review cadence is a recurring prompt to revisit one durable note, check whether it still answers its intended question, and choose a small next action.

## Why it is useful

The cadence makes stale assumptions easier to notice without requiring a full-vault review.
